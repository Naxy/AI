# AI 日报 → 抖音 / 小红书 轮播图

把一堆资讯压成 9 页竖版轮播图 + 两套平台文案。核心不是排版，是**选题排序**和**一页只讲一件事**。

## 工作流

### 1. 读素材，抽取候选

读用户给的日报/文档，把每条的**硬事实和数字**摘出来（日期、百分比、家数、金额、排名）。只有带具体数字的条目才可能是封面素材。

### 2. 打分选 5 条

按 [references/selection.md](references/selection.md) 的五维评分（满分 25）排序，取前 5。同时留 2 条备选，并给出「要流量选 X / 要收藏选 Y」的替换建议。

企业级 API 更新、纯观点、同质化的"更强模型"发布一律排除。

### 3. 排叙事曲线

按 `恐惧 → 更恐惧 → 祛魅 → 希望 → 复杂/切身` 重新排序，**不要沿用日报的原始顺序**。第 5 条优先选与普通人切身相关的（隐私、钱包、工作）。

写一句封面主标题（趋势判断型最稳，≤ 18 字），必须同时回答"发生了什么"和"意味着什么"。

### 4. 出图

复制 `assets/template.html` 到工作目录，**逐页替换文本**，保持结构与 class 不变。模板里已有一套完整的 2026-10-25 示例内容，替换时对照参考信息密度。

必须遵守 [references/design-system.md](references/design-system.md) 里的六条硬规则，尤其是：标题 ≤ 14 字、要点固定 3 条、巨型数字比标题大。

渲染：

```bash
bash scripts/render.sh --html ./carousel.html --out ./out --scale 2
```

不给 `--pages` 时按 HTML 里实际的 `id="pN"` 自动探测页数（清单型 5 页就只出 5 张）。
只能先渲一两页看效果时，用 `--pages "1 2"`。改文案后重跑同一条命令即可，它按 `?p=N` 逐页截图。

### 5. 看图自检

**必须逐页打开 PNG 检查**，不要只看 HTML 就交付。重点看四件事：
- 有没有孤字换行（句末两三个字被挤到下一行）
- 标题是否超过两行
- 巨型数字右侧说明文字是否与数字底部对齐
- 页脚是否只剩页码（**不要出现"来源 xx.com"这类域名行**）

发现问题**改句子长度**，不要调字号或压缩边距。

### 6. 写两套文案

按 [references/copywriting.md](references/copywriting.md) 写 `文案-小红书.md` 和 `文案-抖音.md`，各给 3 个标题备选。

**标签先查 `pipeline/series.json` 里该系列的固定标签**（ai-daily / github / notes 各一套），必须全部出现在小红书文案里；抖音只取前 5 个。小红书固定在 8–10 个区间补垂类，抖音 ≤5 个。`check.py` 会校验缺失。

如果用户可能转视频，附一段 30 秒口播稿（150–180 字）。

### 7. 交付

用 `present_files` 一次性交齐：9 张 PNG 按顺序 + 两份文案。回答里给一张「页 / 内容 / 主视觉数字」的对照表，让用户不用点开就知道每页是什么。

发布方式见 [references/publish.md](references/publish.md)。

## 硬约束

- 画布固定 1080 × 1440（3:4），导出 2 倍图
- 9 页，不多不少：封面 / 5 条内容 / 洞察 / 互动 / 收尾
- 每页一个巨型数字，全页最大字号
- 标题纯白不上色，强调色只给数字、栏目条、短横、金句竖线
- 不用原始新闻配图（版权 + 水印 + 分辨率），一律自制信息卡
- **页脚不标来源**，只留页码（靠右）。媒体域名不进图，需要交代出处就写进正文或置顶评论

## 已知坑

- **Chrome headless 在 macOS 沙箱下会以退出码 133 静默失败**，需要放开沙箱执行 `render.sh`。
- 模板用 `?p=N` 参数控制只显示第 N 页；用 `file://` 路径必须带绝对路径，否则 query 会被截断。
- `PingFang SC` 最粗只到 Semibold，700 和 800 渲染结果相同，不要靠加粗拉层级，靠字号。
